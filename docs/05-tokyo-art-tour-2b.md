# 05. 도쿄 아트 투어 (2-B 해설 프로그램형) 일정 · 가격 설계

> 02 문서 4-2의 "2-B 해설 프로그램" 구조로 만든 첫 해외 검증 상품입니다. 참가자가 항공과 숙박을 각자 해결하고, 현지 일정·입장권·도슨트 해설을 우리가 제공합니다.
> 전시 일정과 요금은 2026년 10월 기준 공개 정보이고, 일부는 아직 미발표라 **확인 필요**로 표시했습니다. 금액은 가정치입니다.

## 1. 상품 개요

| 항목 | 내용 |
|---|---|
| 상품명 (가안) | **모네 100년, 그리고 지금의 미술: 도쿄·하코네 아트 위크엔드** |
| 일정 | **2027년 3월 11일(목) ~ 14일(일), 3박 4일**. 연차 2일(목·금)로 가능 |
| 앵커 이벤트 | **아트페어 도쿄 2027** (도쿄국제포럼) + **모네 사후 100주년** 폴라 미술관 기획전 |
| 구조 | 현지 집합·해산. 항공·숙박 각자 |
| 정원 / 최소 출발 | **15명 / 10명** |
| 가격 | **89만원** (얼리버드 선착순 5명 79만원) |
| 동행 | 크리에이터(도슨트) 1명 + 운영 스태프 1명 |

### 왜 이 날짜인가
- **아트페어 도쿄 2027**이 3월에 도쿄국제포럼에서 열립니다. 공식 사이트 안에서도 3/11~14와 3/12~14 표기가 섞여 있어서, 페어 관람은 두 경우 모두 포함되는 **3/13(토)**에 배치했습니다.
- **폴라 미술관 "모네 사후 100주년 × 현대미술" 기획전**: 보도자료 기준 2027년 4월 7일까지 열릴 예정입니다. 다른 사이트에는 2026년 12월 17일 종료로 나와 있어 **확인이 필요**합니다.
- **모리미술관 "모리 마리코전"**: 2027년 3월 28일까지.
- 벚꽃 성수기(3월 말~4월 초)보다 앞이라 참가자 숙박비 부담이 덜합니다.
- 월요일 휴관이 많은 도쿄 미술관 사정에 맞춰 목~일로 잡았습니다.

## 5. 가격·구조 조정 옵션

| 옵션 | 내용 | 효과 |
|---|---|---|
| **크리에이터 수익 배분형** | 고정 출연료 150만원 → 고정 80만원 + 이익의 일정 비율 | 고정비가 약 70만원 줄어 최소 출발 인원을 8~9명까지 낮출 수 있음. 크리에이터도 모객 동기가 커짐 |
| **2박 3일 라이트** | 하코네(D2) 제외, 목~토 또는 금~일. 가격 약 59만원 | 진입 가격이 낮아짐. 고정비 약 310만원, 변동비 약 23만원으로 10명 기준 소폭 흑자(가정치) |
| **가격 89 → 99만원** | 크리에이터 사인 아트북, 소규모 갤러리 방문 추가 | 팬층이 두터운 크리에이터일 때 |
| **정원 15 → 20명** | 수신기 사용 전제 | 이익은 늘지만 전시실 혼잡과 해설 품질이 떨어짐. 첫 회는 15명 권장 |

**참가자 입장의 총 여행비 (참고):** 상품가 89만원 + 항공 30~50만원 + 숙박 3박 30~60만원(2인 1실 1인분~1인실) + 개인 식비·교통 15~25만원 = **약 165~225만원**.

## 7. 운영 규정 (상세페이지에 고지)

- **집합·해산:** D1 14:00 우에노 집합, D4 13:30 기요스미시라카와 해산
- **합류 실패:** 항공 지연 등 개인 사정으로 놓친 일정은 환불하지 않음. 일정 중간 합류는 가능
- **취소·환불:** 출발 확정일(2/9) 전에는 전액 환불. 이후는 국외여행 표준약관 단계표를 준용하거나 특약으로 명시
- **여행자 보험:** 가입 필수, 출발 1주 전까지 증빙 제출
- **촬영:** 콘텐츠 촬영이 있다는 사실과 얼굴 노출 동의 여부를 신청 단계에서 받음
- **체력:** 하루 1.5만 보 내외, 하코네는 경사로 있음

## 8. 확인 필요 체크리스트

- [ ] **미술관 전시실 내 그룹 해설 가능 여부.** 일본의 많은 미술관은 외부 인솔자의 전시실 내 해설을 제한하거나 사전 신청을 요구합니다. 안 되는 곳은 **전시실 밖 사전 브리핑 + 투어북·오디오 노트 개별 관람**으로 바꿉니다
- [ ] 폴라 미술관 모네전 회기 (2027년 4월 7일까지인지)
- [ ] 아트페어 도쿄 2027 정확한 일반 관람일과 티켓 가격, 단체 구매 가능 여부
- [ ] 아티존 미술관, MOT, 국립서양미술관의 2027년 3월 전시
- [ ] 모리미술관 3/13 야간 개관 시간
- [ ] 웰컴 디너와 살롱 토크 장소 예약 (15명 단체석, 프라이빗 공간)
- [ ] **판매 주체:** 2-B를 직접 판매해도 되는지 관할 구청이나 문화체육관광부에 문의(02 문서 4-2). 안 되면 여행사 상품으로 판매
- [ ] 환율 변동 대비: 엔화 비용은 판매 확정 후 일괄 환전하거나 엔화 결제 카드로 고정
