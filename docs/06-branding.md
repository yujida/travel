# 06. 브랜딩 제안 · 인스타그램 공동구매형 런칭

> 전제: 첫 상품은 05 문서의 도쿄 아트 투어(1인 호스트 + 현지 전문가, 정원 12명)이고, **2026년 12월 중순 공동구매형 오픈**을 목표로 합니다. 지금(10월 말)부터 약 7주 동안 브랜드를 먼저 쌓습니다.

## 1. 왜 공동구매형이 이 상품에 맞나

| 인스타 공구의 특징 | 우리 상품에 대응되는 것 |
|---|---|
| 믿을 만한 사람이 골라준다 | 호스트의 큐레이션 (어떤 전시를, 왜 지금 보는가) |
| 기간 한정 오픈 (보통 며칠) | 오픈 기간 5일, 이후 마감 |
| 수량 한정 · 공구가 | 정원 12석, 얼리버드 4석 |
| 오픈 전 티징과 "알림 신청" | 사전 알림 신청 = 수요 검증 데이터 |
| 공구 후 후기 리그램 | 여행 후기 → 다음 상품 모객 |

**전제 조건:** 공구는 결국 **"이 사람이 추천하면 믿는다"**는 신뢰에서 팔립니다. 그래서 브랜드는 두 층으로 설계합니다.
- **브랜드 계정**: 큐레이션, 상품, 후기가 쌓이는 곳
- **호스트(대표) 퍼스널 계정 또는 얼굴**: 답사, 준비 과정, 취향이 보이는 곳. 공구 오픈은 여기서 함께 알림

## 2. 브랜드 방향 3안

### A안. **한점** (추천)
- **의미:** "작품 한 점을 만나러 가는 여행". 여행 중 매일 밤 하는 리추얼 "오늘의 한 점"(05 문서 일정)이 그대로 브랜드가 됩니다
- **슬로건 예시:** "단 한 점을 위해 떠나는 여행" / "여행이 끝나도 남는 한 점"
- **톤:** 차분하고 감도 높게, 하지만 어렵지 않게. "미술 잘 몰라도 괜찮아요"
- **타깃:** 2030 전시 덕후 직장인 (02 문서 페르소나 1)
- **비주얼 모티프:** **점 하나(●)**. 로고, 사진 프레임, 문장 끝 마침표, 지도 위 목적지 표시까지 하나의 점으로 통일
- **커뮤니티 이름:** 한점러 / **굿즈:** "한점 여권" (참여할 때마다 스탬프 하나)
- **장점:** 짧고 기억하기 쉬우며 어떤 상품(도쿄, 카셀, 국내 전시)에도 붙음. 시리즈 콘텐츠로 만들기 좋음
- **단점:** 일반 단어라 상표 등록과 검색 노출이 어려울 수 있음 → 영문 표기(HANJEOM)나 조합형(한점여행, 한점클럽)으로 보완

### B안. **아트원정대** (Art Away)
- **의미:** 축구 팬들이 "원정 경기"를 보러 가듯 전시를 보러 원정을 떠난다. 축구 직관 투어 모델을 그대로 브랜드로 가져온 안
- **슬로건 예시:** "이번 시즌, 우리는 카셀로 원정 갑니다"
- **톤:** 유쾌하고 팬덤스러움. 시즌제("2027 시즌 일정 발표"), 원정 머플러 대신 **원정 스카프·에코백**
- **장점:** 축구 투어처럼 공동체감과 재미가 강하고, 시즌 일정 발표 자체가 이벤트가 됨
- **단점:** 미술의 고급스러운 이미지와 부딪힐 수 있음. 입문 컬렉터층(페르소나 2)에는 가볍게 느껴질 수 있음

### C안. **그랜드투어 클럽** (Grand Tour Club)
- **의미:** 18세기 유럽 청년들이 예술을 보러 떠났던 "그랜드 투어"에서 따옴. 2027년 카셀·뮌스터·바젤 시그니처 투어와 바로 연결됨
- **톤:** 클래식, 교양, 프리미엄
- **장점:** 스토리가 강하고 고가 상품과 잘 맞음. 컬렉터층에 어울림
- **단점:** 도쿄 3박 4일 같은 가벼운 상품에는 무겁고, 2030 타깃에게 거리감이 있음

**추천:** **A안 "한점"**을 메인 브랜드로 쓰고, B안의 장치(시즌 일정 발표, 원정 굿즈)와 C안의 스토리(2027 그랜드 투어)는 **캠페인 이름**으로 가져옵니다.
- 예: "한점 2027 시즌" / 시그니처 상품명 "한점 그랜드 투어 2027"

## 3. 브랜드 기본 설계 (A안 기준)

| 항목 | 내용 |
|---|---|
| 브랜드 한 문장 | 좋아하는 사람들과 세계의 전시를 보러 가고, 각자의 한 점을 가지고 돌아오는 여행 |
| 약속 3가지 | ① **큐레이션**: 지금 꼭 봐야 할 전시만 ② **투명성**: 가격 구성을 모두 공개 ③ **소규모**: 12명 내외, 대화가 되는 인원 |
| 말투 | 친구에게 추천하듯 존댓말. 전문용어는 풀어서. 과장 금지("인생 여행" 같은 표현 지양) |
| 컬러 | 갤러리 화이트(배경) + 차콜(글자) + **포인트 컬러 하나**(예: 모네 수련의 블루 또는 주홍). 포인트 컬러는 "점"에만 사용 |
| 서체 | 본문은 가독성 좋은 고딕, 제목은 얇은 명조로 전시 도록 느낌 |
| 사진 스타일 | 작품 앞 뒷모습, 손에 든 티켓, 미술관 건축 디테일, 지도 위의 점. 얼굴보다는 장면 |
| 로고 | 워드마크 "한점" + 마침표처럼 찍힌 점 하나 |

**런칭 전에 확인할 것:** 특허정보검색서비스(KIPRIS)에서 상표 검색, 인스타 핸들·도메인 확보 여부. 겹치면 조합형으로 바꿉니다.

## 4. 인스타그램 계정 설계

- **프로필:** "전시를 보러 떠나는 소규모 아트 여행 | 다음 여행: 도쿄 2027.3 | ▼ 오픈 알림 신청"
- **링크:** 사전 알림 신청 폼 (이름, 연락처, 관심 여행, 예산대, 마케팅 수신 동의). 03 문서의 v0 랜딩
- **하이라이트:** 소개 / 다음 여행 / 오늘의 한 점 / 답사기 / FAQ / 후기
- **그리드:** 3칸 단위로 시리즈 색을 맞춰 통일감

## 5. 콘텐츠 기둥 (런칭 전 7주 동안 주 3~4회)

| 시리즈 | 형식 | 목적 |
|---|---|---|
| **오늘의 한 점** (시그니처) | 작품 한 점을 3장 카드로: 작품 → 이야기 → "직접 보면 다른 점" | 브랜드 정체성, 저장 유도 |
| **이번 달 해외 전시 캘린더** | 월 1회 카드 | 저장·공유. "이걸 보러 같이 가자"로 자연스럽게 연결 |
| **호스트 답사기** | 릴스, 스토리 | 도쿄 사전 답사, 동선 테스트. 사람에 대한 신뢰 쌓기 |
| **가격은 이렇게 만들어져요** | 카드 | 투명성 약속 실천. 이스타TV 논란과 정반대 포지션 |
| **미술관·아트페어 꿀팁** | 릴스 | 휴관일, 입장권, 아트페어 관람법. 검색·공유 유입 |
| **전문가 미리보기** | 인터뷰 카드, 짧은 영상 | 섭외한 현지 전문가 소개(사전 동의). 상품 가치 예고 |
| **국내 번개 모임** | 공지 → 후기 | 국내 전시 함께 보기(무료 또는 소액). 오프라인 첫 만남과 첫 후기 확보 |

## 6. 공동구매형 런칭 일정 (도쿄 상품 기준)

| 시기 | 단계 | 할 일 |
|---|---|---|
| 10월 말~11월 초 | **준비** | 이름 확정, 상표·핸들 확인, 로고와 템플릿 제작, 계정 개설, 알림 신청 폼 |
| 11월 | **신뢰 쌓기** | 콘텐츠 기둥 주 3~4회. 국내 번개 모임 1회 (예: 국립현대미술관 또는 리움) |
| 11월 말 | **티징** | "12월, 첫 여행을 엽니다" 카운트다운. 목적지 퀴즈 ("이 미술관은 어디일까요?") |
| 12월 초 | **사전 알림 모집** | 댓글·DM으로 "알림" 신청 → 자동 DM으로 폼 안내. 상세 일정 일부와 가격 구성 미리 공개 |
| 오픈 전날 | **라이브** | 인스타 라이브 Q&A: 일정, 가격 구성, 혼자 참여해도 되는지 |
| **12월 중순 (5일간)** | **공구 오픈** | 알림 신청자 우선 오픈(24시간 선공개) → 일반 오픈. 남은 좌석을 스토리로 실시간 공유. 얼리버드 4석 → 정가 |
| 오픈 마감 후 | **마감 공지** | 대기 신청 접수 → 다음 회차 수요 |
| 여행 중·후 | **후기** | 참가자 리그램, "한점 여권" 스탬프, 리뷰 라이브 → 다음 상품 티징 |

**런칭 전 목표 지표 (가설):** 팔로워 수보다 **사전 알림 신청자 수**가 핵심입니다. 신청자 중 실제 구매로 이어지는 비율이 낮다고 보고, 정원 12명의 여러 배를 목표로 잡습니다(예: 100명). 저장 수, DM 문의 수, 번개 모임 참여자 수를 함께 봅니다.

## 7. 공동구매 방식에서 지켜야 할 것

- **판매자 정보 표시:** 공구도 통신판매입니다. 판매 페이지에 상호, 대표자, 사업자등록번호, 통신판매업 신고번호, 연락처, 취소·환불 규정을 표시합니다
- **여행 상품 규정:** 직접 판매하면 여행업 등록 문제가 그대로 남습니다(02 문서 4-2). 여행사 상품이면 "계약 당사자는 ○○여행사" 고지
- **협찬·광고 표시:** 전문가나 다른 인플루언서가 대가를 받고 홍보하면 "광고", "협찬" 같은 경제적 이해관계를 표시해야 합니다(표시광고법 추천·보증 심사지침)
- **최소 출발 인원과 확정일**을 오픈 공지에 함께 적습니다 (도쿄: 최소 9명, 출발 30일 전 확정)
- **DM 결제 금지:** 결제는 반드시 정식 결제 페이지에서. DM 계좌이체 판매는 신뢰와 소비자 보호 양쪽에서 위험합니다

## 8. 바로 할 일

1. 브랜드 3안 중 방향 결정 (또는 다른 이름 후보 추가)
2. KIPRIS 상표 검색, 인스타 핸들·도메인 확인
3. 로고·색·서체 확정 → 카드뉴스 템플릿 3종 (오늘의 한 점 / 캘린더 / 공지)
4. 사전 알림 신청 폼 + 프로필 링크
5. 첫 2주 콘텐츠 8개 기획
