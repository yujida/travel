# 02. 상품 설계

> 브랜드명은 미정이며, 이 문서에서는 "(가칭) 아트트립"으로 씁니다.

## 1. 한 줄 컨셉

**"좋아하는 아트 크리에이터와 함께, 세계적인 전시를 보러 떠나는 여행"**
축구 유튜버의 직관 투어에서 *경기*를 *전시·비엔날레·아트페어*로, *관전 해설*을 *작품 해설과 토크*로 바꾼 상품입니다.

## 2. 포지셔닝

| | 일반 패키지 | 교수·도슨트 동행 미술 여행 (기존) | **(가칭) 아트트립** |
|---|---|---|---|
| 핵심 가치 | 가성비, 명소 | 깊이 있는 강의 | **사람·커뮤니티 + 해설 + 한정 이벤트** |
| 분위기 | 관광 | 강의형, 중장년 중심 | 팬미팅형·살롱형, 2040 |
| 콘텐츠 | 없음 | 현장 해설 | 사전 라이브 → 현장 해설 → 귀국 후 콘텐츠·굿즈 |
| 테마 | 루브르·바티칸 | 고전·인상주의 | 인상주의 + **현대미술·비엔날레·아트페어** |

## 3. 타깃 페르소나

1. **전시 덕후 직장인 (29~38세, 여성 비중 높음)**: 국내 대형 전시와 프리즈 서울을 챙겨 보는 층. 연차를 아껴 "의미 있는 해외여행"을 원합니다. 혼자 가기는 부담스럽고, 같은 취향인 사람들과 가고 싶어 합니다.
2. **입문 컬렉터 (35~50세)**: 아트페어에서 작품을 사기 시작한 층. 아트바젤이나 프리즈에 "제대로" 가 보고 싶지만 동선과 네트워크가 막막합니다. 가격 저항이 낮은 대신 품질 기대치가 높습니다.
3. **크리에이터의 오랜 팬 (전 연령)**: 그 사람의 해설을 현장에서 직접 듣는 것이 목적입니다. 상품보다 사람을 보고 삽니다.

## 4. 운영 구조 (가장 중요한 결정)

해외 패키지를 기획해서 **대금을 직접 받고 판매하려면 여행업 등록이 필요합니다**(관광진흥법). 그래서 초기 구조는 셋 중 하나를 골라야 합니다.

| 모델 | 구조 | 장점 | 단점 |
|---|---|---|---|
| **A. 여행사 협업 (추천·초기)** | 여행사가 상품 등록, 계약, 결제, 운영을 맡고, 우리는 기획·크리에이터 섭외·모객·콘텐츠를 맡음 | 등록·보증보험·PG 부담이 없고, 바로 시작할 수 있음. 하나투어×교보, 모두투어×제이풋볼과 같은 구조 | 마진 일부만 가져옴. 상세페이지와 고객 데이터가 여행사 쪽에 남음 |
| B. 직접 여행업 등록 | 국내외여행업 등록(자본금 3천만원 이상, 사무실, 보증보험 + 기획여행 보증보험 추가) | 마진과 고객 데이터, 브랜드를 모두 소유 | 초기 비용과 리스크가 큼. PG사는 여행업을 고위험 업종으로 보고 업력·신용을 심사함 |
| C. 플랫폼 (장기) | 여러 크리에이터가 상품을 여는 TrovaTrip형 마켓 | 확장성 | 거래액이 충분히 쌓인 뒤에 할 일 |

**추천 경로:** A로 첫 2~3개 상품을 검증하고, 반복 수요가 확인되면 B(직접 등록)로 전환합니다. 앱이 쌓이면 C로 확장합니다.

### 모델 A에서 여행사와 정할 것
- 수익 배분: 1인당 기획료(정액) 방식과 판매가의 %(수수료) 방식 중 무엇으로 할지
- 크리에이터 동행 비용(항공·숙박·체재비)을 원가에 넣는 방식
- 상세페이지 제작 주체, 우리 사이트에서 여행사 결제 페이지로 넘기는 방식
- 고객 데이터(연락처, 마케팅 수신 동의)를 공유하는 범위
- 최소 출발 인원과 출발 확정 시점, 행사가 취소될 때의 처리
- 단체 항공좌석·객실 블록을 확보하는 시점과 계약금 부담 주체

### 여행사 후보와 컨택 순서
1. **아트 전문 여행사**(예: 아트투어/유앤지투어): 바젤 아트페어 운영 경험이 있어 동선 노하우가 있음
2. **대형사 테마팀**(하나투어 전문가 동반여행, 모두투어 컨셉투어, 노랑풍선): 모객력과 신뢰도. 크리에이터 협업 선례가 있음
3. **중소 테마 여행사**(트래블링, 투어그림 등): 의사결정이 빠르고 유연함

### 4-1. 인원 기준: 몇 명이면 여행사와 협의가 되나

"몇 명부터 협의 가능"이라고 정해 둔 기준은 없습니다. 여행사가 실제로 따지는 것은 **"그 인원이면 출발(원가)이 성립하는가"와 "그 인원을 모을 수 있다는 근거가 있는가"** 두 가지입니다.

**사례**

| 사례 | 인원 | 가격 |
|---|---|---|
| 모두투어 × 페노, 유럽 축구 직관 컨셉투어 (2025) | 오리엔테이션 참석 **32명** | 859만원 |
| 모두투어 NBA·MLB 직관 컨셉투어 (2025) | 7회 운영, 누적 **210명** (회차당 약 30명) | 500~700만원대 |
| 같은 시리즈 설명 기사 | **회차당 25~35명**, 거의 전 회차 매진 | |
| 모두투어 × B Story, NBA 직관 컨셉투어 | 30분 만에 매진, 예약 대기 **280여 명** | |

| 교원투어 / 롯데관광 소규모 상품 | 최소 출발 8명 / 최소 15명·최대 39명 | |
| 해외 맞춤 프라이빗 투어 (Inspiring Vacations) | 최소 4명 | 인원이 적을수록 1인가 상승 |
| TrovaTrip | 트립마다 최소 인원 설정. 출시 후 14일 안에 예약 2건 미만이면 취소될 수 있음 | |

**인원 구간별 의미** (위 사례와 업계 관행을 바탕으로 한 해석)

| 인원 | 의미 |
|---|---|
| 4~9명 | 맞춤 프라이빗 투어로는 가능하지만 1인당 비용이 높음. 테스트용 |
| **10명 이상** | 대부분의 항공사가 단체 운임을 적용하는 기준. **풀패키지 상품화의 하한선** |
| **15명 안팎** | 인솔자와 크리에이터 동행비가 나눠져 원가가 맞기 시작함. 일반적인 최소 출발 인원 |
| **20~30명** | 버스 한 대, 그룹 해설이 가능한 규모. 크리에이터 투어에서 가장 많이 쓰는 정원 |

**적용:** 시그니처 상품은 **정원 25명, 최소 출발 15명**으로 제안합니다. 여행사에 처음 연락할 때는 "정원 25명, 최소 출발 15명, 사전 신청 ○○명 확보"처럼 **수요 근거와 함께** 제안하세요. 인솔자 무료 좌석(흔히 말하는 "15+1" 같은 조건)은 항공사와 계약마다 달라서 견적을 받을 때 따로 확인해야 합니다.

### 4-2. 라이트 모델: 현지 합류형 (항공·숙박은 각자, 현지 일정과 도슨트만)

처음부터 풀패키지를 꾸리기 부담스러울 때의 대안입니다. 참가자가 항공(과 숙박)을 각자 해결하고 **현지에서 만나**, 우리는 일정과 해설만 맡습니다.

**두 가지 변형**

| | 2-A. 랜드 패키지 | 2-B. 해설 프로그램 |
|---|---|---|
| 각자 해결 | 항공 | 항공 + 숙박 |
| 우리가 제공 | 숙박 + 현지 교통 + 입장권 + 일정 + 도슨트 | 일정 + 도슨트 (+ 입장권, 현지 이동) |
| 시그니처 상품 기준 1인가 (02-6 원가표에서 역산한 가정치) | 약 400~570만원 | 약 240~330만원 |
| 최소 인원 | 8~10명 (단체 항공 운임 기준이 사라짐) | 6~8명 (도슨트 동행비를 나눌 최소 규모) |
| 비슷한 기존 형태 | 여행사 "현지 합류" 상품 | 마이리얼트립·와그의 한국어 미술관 투어(입장권 불포함, 수신기 포함 등), 에어비앤비 체험(최대 16명) |

**장점**
- **가격 장벽이 낮음:** 가장 비싼 항공이 빠져 표시 가격이 절반 수준으로 내려감
- **참가자의 자유도:** 마일리지 사용, 앞뒤로 개인 여행 연장, 출발 도시 선택이 가능
- **우리의 리스크 감소:** 항공 단체석 계약금, 좌석 미판매 손실이 없음
- **빨리 시작할 수 있음:** 수배할 항목이 적어 준비 기간이 짧고, 최소 인원도 낮음

**단점과 대응**

| 단점 | 대응 |
|---|---|
| 1인당 매출이 낮음 | 도슨트·기획의 가치를 앞세운 가격 설계. 출발 전 유료 클래스, 굿즈로 보완 |
| 항공 지연이나 결항으로 합류 실패 | 집합 시간은 첫날 오후 이후로 잡고, 놓친 일정은 환불하지 않는다는 규정을 명시. 여행자 보험 가입을 필수로 |
| 숙소가 흩어지면 집합과 이동이 번거로움 | 2-B는 "추천 숙소 2~3곳"을 지정. 행사 기간에 숙소가 부족한 도시(카셀, 바젤)는 **2-A로 숙박을 포함**하거나 단체 객실 블록을 잡아 예약 코드를 제공 |
| 함께 출발하는 데서 오는 유대감이 약함 | 출발 전 온라인 오리엔테이션, 단톡방, 현지 첫날 웰컴 디너로 보완 |
| 현지 해설 규제 | 일부 국가·미술관은 단체 해설에 **현지 자격 가이드**를 요구하거나(이탈리아 등) 단체 예약과 수신기 사용을 의무화함. 상품별로 확인하고, 필요하면 현지 자격 가이드와 공동 진행 |

**법규상 주의 (중요):** 관광진흥법상 여행업에는 시설 이용 알선이나 계약 대리뿐 아니라 **"여행에 관한 안내"와 "그 밖의 여행 편의 제공"도 포함**됩니다. 항공을 빼더라도 숙박·입장권·현지 교통을 묶어 판매하면 여행업에 해당할 가능성이 높고, 해설만 판매하는 2-B도 판단이 애매합니다. 그래서:
1. 2-A는 **여행사 상품(현지 합류형)으로 판매**하거나 직접 여행업을 등록한 뒤 판매
2. 2-B를 직접 판매하려면 시작 전에 관할 구청 관광과나 문화체육관광부에 해당 여부를 문의하고(유권해석), 여행 전문 법률가의 검토를 받기

**추천:** 현지 합류형은 **첫 단계로 좋은 선택**입니다. 순서는 이렇게 제안합니다.
1. **도쿄 미술관 2-B**(3박 4일, 정원 10~15명): 가장 가볍게 수요와 운영을 검증
2. **2027 그랜드 아트 투어 2-A**(숙박 포함, 정원 20~25명): 카셀·바젤은 행사 기간에 숙소 확보가 관건이라 숙박은 우리가 맡음
3. 반복 수요가 확인되면 항공까지 포함한 **풀패키지**(모델 A·B)로 확장

## 5. 상품 라인업 (사다리 구조)

| 단계 | 상품 | 기간 | 예상 가격대 | 목적 |
|---|---|---|---|---|
| ① 입문 | 국내 전시 투어 + 크리에이터 토크 (광주비엔날레, 리움, 지역 미술관) | 당일~1박 | 10~30만원 | **수요 검증**, 팬 모으기, 후기 콘텐츠 확보 |
| ② 단거리 | 도쿄 미술관 투어 / 나오시마 / 아트바젤 홍콩 | 3박 4일~4박 5일 | 150~300만원 | 첫 해외 상품. 하나투어 도쿄 미술 기행이 매진된 선례가 있음 |
| ③ 클래식 | 파리 인상주의 (오르세·오랑주리·지베르니·오베르) | 7~9일 | 400~600만원 | 검증된 스테디 테마 |
| ④ 시그니처 | **2027 그랜드 아트 투어** (아래) | 9박 10일 내외 | 600~800만원대 | 브랜드를 대표하는 상품, 화제성 |

> 가격대는 기존 상품과 업계 상식에 기댄 **가정치**입니다. 실제 판매가는 여행사 견적으로 확정합니다.

## 6. 시그니처 상품 예시: 2027 그랜드 아트 투어

**콘셉트:** 10년에 한 번 도쿠멘타 16과 뮌스터 조각 프로젝트(50주년), 아트바젤이 같은 주에 겹칩니다. 이 셋을 크리에이터와 함께 걷는 9박 10일입니다.

| 일자 | 일정 | 포인트 |
|---|---|---|
| D1 (6/13 일) | 인천 → 프랑크푸르트 → 카셀 (ICE 약 1.5시간). 웰컴 디너 | 크리에이터 오프닝 토크 "도쿠멘타는 왜 5년마다 논쟁이 되는가" |
| D2 (6/14) | 도쿠멘타 16 하루 종일 (프리데리치아눔, 도쿠멘타 할레 등) | 크리에이터와 그룹 해설 동선 |
| D3 (6/15) | 도쿠멘타 오전 자유 관람 → 오후 카셀 → 뮌스터 이동 | 저녁 "오늘 본 작품 한 점" 살롱 토크 |
| D4 (6/16) | 뮌스터 조각 프로젝트, **자전거 투어** | 자전거 도시 뮌스터의 특성을 살린 체험 |

## 7. 고객 여정 (축구 투어 공식을 그대로 적용)

```
콘텐츠(유튜브·인스타 전시 리뷰)
  → 사전 알림 신청·설문 (가고 싶은 행사·예산·일정)        ← 수요 검증
  → 얼리버드 오픈 / 한정 20~25명 판매                       ← 매진 연출
  → 출발 전 온라인 오리엔테이션 라이브 (관람 포인트 예습)     ← 모두투어×페노 방식
  → 현장: 그룹 해설 + 자유 관람 + 저녁 살롱 토크
  → 귀국 후: 리뷰 라이브, 단체 사진집·아트북 굿즈, 동창회 모임 ← 재구매·바이럴
```

## 8. 수익원
1. 여행 상품 기획료·수수료 (메인)
2. 출발 전 **유료 온라인 클래스**: 여행을 가지 않는 팬도 구매할 수 있음
3. 굿즈: 투어 아트북, 에코백, 엽서 세트
4. 귀국 후 콘텐츠 (유튜브 광고, 브랜드 협찬)
5. (장기) 앱 기반 오디오 해설, 국내 전시 투어 정기 멤버십

## 9. 법규·계약 체크리스트

- [ ] 운영 모델 결정 (A 여행사 협업 / B 직접 등록 / 4-2 현지 합류형)
- [ ] 현지 합류형을 직접 판매하는 경우: 여행업 해당 여부를 관할 구청 또는 문화체육관광부에 문의(유권해석)하고 법률 검토
- [ ] 방문 국가·미술관의 단체 해설 규정 확인 (현지 자격 가이드 필요 여부, 단체 예약, 수신기, 그룹 인원 상한)
- [ ] B인 경우: 국내외여행업 등록 (자본금 3천만원 이상, 사무실 사용권, 보증보험 가입, 기획여행 보증보험 추가). 현행 금액은 국가법령정보센터의 **관광진흥법 시행령 별표 1, 시행규칙 별표 3**으로 확인
- [ ] 통신판매업 신고 (온라인 판매 시)
- [ ] 국외여행 표준약관 기반 약관과 취소·환불 규정. 표준약관 기준은 출발 30일 전까지 전액 환불, 이후 10%·15%·20%·30%·50%로 단계 상향. 특약을 쓰면 특약 내용을 별도로 명확히 고지
- [ ] **최소 출발 인원과 출발 확정 통보 시점 고지.** 한국소비자원 조사에서 최소 출발 인원을 미리 알린 투어는 22%에 그쳤고, 출발 1~3일 전 취소 통보가 주요 피해 유형이었음
- [ ] 크리에이터 계약: 동행 일수, 콘텐츠 촬영 권리, 참가자 초상권(촬영 동의서), 불참할 때의 대체 방안
- [ ] 여행자 보험, 현장 안전 매뉴얼
- [ ] 개인정보 처리방침 (여권 정보 등 민감 정보 포함)
