# travel
travel for art watching

예술과 전시를 테마로, 아트 크리에이터와 함께 세계적인 전시·비엔날레·아트페어를 보러 떠나는 여행 상품 프로젝트입니다.
축구 유튜버의 해외 직관 투어 모델을 예술 분야에 적용합니다.
